所有的线段都有两个端点。开线段是在常规线段的基础上建立起来的，没有常规线段就没有开线段。开线段是常规线段的衍生物。也就是说开线段不可能单独存在，你不可能说我就直接画一条开线段，那是不可能的（因为下笔的时候就有一个点，然后提笔的时候还有一个点，所以这样子画出来的每一条线段都是有两个点的）。虽然说后面有符号可以直接表示开线段，但是我们要知道开线段的来源。所以当我们谈论开线段的时候，我们不能忘了后面它基于的原线段（尤其是相关的点），因为如果没有原来的线段的话，或者说没有相关的点的话，那么开线段也就是不存在的。



真的是要先有那个点之后，才能够谈论包含那个点的线段，或者说没有那个点的看线段。所以首先是要有那个点，然后才谈论线段。这个先后顺序一定要搞清楚。



当我们谈论任何一条直线段的时候，我们都很清楚它有两个端点，但是当我们谈论开区间所对应的线段的时候，因为它的特殊性，所以他的两个端点怎么说呢？应该理解成变异的线段吧，因为正常的线段或者说是闭期间对应的线段，它是包含两个点的，但是这里我们又来了一个纯理论上的操作，去两个端点，这时候就产生了这种变异的线段，它的两个端点是被去掉的，这时候我们能说这条线段没有端点吗？或者说这条线段有新的端点吗？很显然我们不能够按照后面这种说法来讲，否则的话，新的端点和原来的点之间又会存在无数多个点。

I hold two basic opinion that 

(1) Every line segment has two endpoints.

(2) The endpoint of a line segment is part of it.

So as for the line segment corresponding to [0,1],  If we remove its right endpoint,  which number corresponds to the right endpoint of the new line segment?  I don't think the number is still 1,  because we have already removed the point corresponding to 1,  thus created this new line segment, the point 1 is not part of the new line segment, so according to my opinion (2), I don't think the number is 1.
