While this solves the logical problem, one could argue that the philosophical problem remains. It seems natural that a set of individuals ought to exist, so long as the individuals exist. Indeed, [naive set theory](https://en.wikipedia.org/wiki/Naive_set_theory)
 might be said to be based on this notion. Although Zermelo's fix allows a [class](https://en.wikipedia.org/wiki/Class_(set_theory))
 to describe arbitrary (possibly "large") entities, these predicates of the [meta-language](https://en.wikipedia.org/wiki/Meta-language)
 may have no formal existence (i.e., as a set) within the theory. For example, the class of all sets would be a [proper class](https://en.wikipedia.org/wiki/Proper_class)
. This is philosophically unsatisfying to some and has motivated additional work in [set theory](https://en.wikipedia.org/wiki/Set_theory)
 and other methods of formalizing the foundations of mathematics such as [New Foundations](https://en.wikipedia.org/wiki/New_Foundations#How_NF.28U.29_avoids_the_set-theoretic_paradoxes)
 by [Willard Van Orman Quine](https://en.wikipedia.org/wiki/Willard_Van_Orman_Quine)
