**写下载功能的方法**

方法一：写Python3的module（模块）

每个module里必须包括parse这个函数，形如


```
def parse(url):
    ...
    return returnValue
```
输入值：
string类型的url，代表的是要下载的资源所在页的网址，比如
```
"http://www.51voa.com/VOA_Special_English/was-mars-less-red-long-ago-70125.html"
```
输出值：
dict类型的returnValue，只能有一个key，也就是这个dict的长度为1。要下载的文件名（string类型）作为key，文件名不要包括文件类型的扩展名。资源的下载链接（string类型）组成的列表作为dict的value（很显然是list类型了~），最简单的形式比如

```
{'Was Mars -- The Red Planet -- Once White?':['http://downdb.51voa.com/201606/was-mars-less-red-long-ago.mp3']}
```
稍微复杂一点的另外一种就是一个要下载的资源有不止一个下载链接的情况，比如我们要下载的一个优酷视频被分作了好几段，那么这时候返回值应该形如

```
{'fileName':['downloadUrl1','downloadUrl2','downloadUrl3',...]}
```

fileName和downloadUrl都是string类型，你不必处理文件的下载链接里包含的重定向。

按照上面的方法，比如你最终写了一个叫youku.py的Python3的module（模块），那么我们就可以这样用它了

```
import youku
downloadPair=youku.parse('http://v.youku.com/v_show/id_XNjkwODUzNjM2.html')
```


方法二：把写好的程序编译成单个可执行文件（无语言限制）

推荐在Linux上面将其编译成单个可执行文件，Windows？也可以！

比如你最终做了一个叫youku的单个可执行命令行文件，那么我们就可以这样用它了

```
youku http://v.youku.com/v_show/id_XNjkwODUzNjM2.html
```
它返回的结果应该和上面一种方法的输出值一样。
